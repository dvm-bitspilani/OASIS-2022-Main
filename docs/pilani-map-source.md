# BITS Pilani map source

The former `maps.google.com` embed returned HTTP 404 during desktop/mobile review. The existing menu map panel now displays a local map made from actual OpenStreetMap geometry. Selecting the map opens Google Maps at the real campus location. Opening the menu does not request an external map, geocoder, tile or iframe.

The data was retrieved on **2026-10-02** from the [OpenStreetMap data API](https://api.openstreetmap.org/api/0.6/map?bbox=75.571,28.349,75.604,28.373). The bounded query covers longitude **75.571–75.604** and latitude **28.349–28.373**. Only relevant way geometries and their original classification/name tags are retained in `pilani-map-data.json.gz`; its 1,148 features are a reproducible, attributed data extract, not a new invented campus layout. The source extract is © OpenStreetMap contributors and licensed under the [Open Database License 1.0](https://opendatacommons.org/licenses/odbl/1-0/). See [OpenStreetMap attribution and licence information](https://www.openstreetmap.org/copyright).

The campus polygon is OpenStreetMap **way 31121508**, named “Birla Institute of Technology and Science - BITS”, tagged `amenity=university`. Its bounds are longitude **75.5828999–75.5940123**, latitude **28.3510053–28.3670560**. The marker and Google Maps destination use its area centroid, **28.3585942, 75.5884245**, which is inside that boundary. Campus identity/address is also supported by the [official BITS Pilani campus page](https://www.bits-pilani.ac.in/pilani/).

`node scripts/generate-campus-map.mjs` renders both static SVGs offline from the committed source extract. Roads, buildings, green spaces, water and the campus boundary use real coordinates projected in Web Mercator with north upwards. It removes drawing detail smaller than half an SVG pixel and rounds coordinates to one decimal drawing pixel; the source geometry remains intact in the data file. Desktop and mobile outputs use different aspect ratios and the same campus center. The map label uses the campus's familiar name; road names come from source tags. This is a contemporary navigation map, not a claim about the campus's 2022 geometry or event records.

The displayed map includes a visible **© OpenStreetMap contributors** link to the copyright/licence page. Its SVG description also contains attribution. The compressed source extract and generator are repository records and are excluded from the deployment artifact. The rendered SVGs are Vite imports with content hashes and immutable caching; the selected responsive map image loads when the existing menu opens. No OSM tiles were downloaded or bundled.
